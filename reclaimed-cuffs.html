: phase001 : cutting up

the only reason i made this project in the first place was because i wanted to see what i could make using only things from the large amount of materials i've amassed in the pursuit of making things. there was a leather purse i only bought so i could use some hardware from it for another project, so i decided to continue the decemation of that purse by cutting it up to use for this.

: phase002 : chainmailing

i assumed this bit would be easiest for me but was probably the most time consuming part of the entire process. i found a chainmail pattern i liked (that would lie flat against the skin) and made enough to use for the cuffs. next time, i need smaller pliers than the ones i used

: phase003 : threading

i knew i wanted to add some chainmail pieces into it some way, so i decided to punch holes through the leather that i could then thread the chainmail through

: phase004 : finishing touches

to finish everything off, i added some grommets to the back and threaded cord through them!
